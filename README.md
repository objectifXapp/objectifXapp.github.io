# Objectif X

Une app gratuite pour réviser le bac, pour toutes les terminales : fiches, cartes, quiz, questions types, sujets corrigés et séances guidées.

- Sans compte, sans publicité : les progrès restent sur le téléphone.
- Marche sans internet une fois installée.
- Les chapitres suivent les programmes officiels de terminale.

Une erreur dans une fiche ou une question ? Écris à objectifx.contact@gmail.com.
